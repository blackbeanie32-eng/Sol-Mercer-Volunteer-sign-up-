AI connection

Google's Gemini API has a genuine free tier — no credit card, no expiration — so it's the default here and keeps this system at $0. It comes with two tradeoffs worth knowing: rate limits (roughly 1,000–1,500 requests/day, plenty for periodic fundraising analysis), and Google may use free-tier prompts to improve its products, so avoid pasting in donor names or other personal details (the built-in prompts below only ever send financial figures and category labels, never donor identities). A paid Anthropic option is also available if you'd rather use Claude and don't mind a small per-call cost.

Free — no billing required. Get a key at aistudio.google.com/apikey by signing in with a Google account and clicking "Create API key."

Your key is sent straight from this browser tab to the endpoint above with each request — it is never stored on a server by this app. Leave "remember" unchecked on a shared computer. If direct browser calls are ever blocked (CORS), deploy a small Google Apps Script Web App that forwards the request server-side and use it as a custom proxy URL — that also keeps the key out of the browser entirely and is itself free to run.
